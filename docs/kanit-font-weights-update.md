## อัปเดต Hosting บน Mac

ดาวน์โหลด ZIP แล้วแตกไฟล์:
https://github.com/bossbazz98/korea-watch/archive/refs/heads/codex/kanit-font-weights-2026-11-12.zip

```bash
cd ~/Downloads/korea-watch-codex-kanit-font-weights-2026-11-12
npm --prefix worker ci
npm --prefix worker run deploy:hosting
```

รุ่นนี้เปลี่ยนเฉพาะฟอนต์และหน้าจอ ใช้ deploy Hosting อย่างเดียว ไม่ต้องตั้ง Firebase ใหม่ ไม่ต้อง deploy rules หรือรัน Fetch news เพื่อเปลี่ยนฟอนต์ ปิดแอปให้หมดแล้วเปิดใหม่ และโหลดรุ่นใหม่เมื่อแอปแจ้ง

รวมงานที่อยู่ใน main ล่าสุดแล้ว เจ้าของเป็นผู้ตรวจและ merge PR เอง
