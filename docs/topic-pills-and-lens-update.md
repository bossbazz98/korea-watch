# อัปเดตหมวดข่าว ฟอนต์ และเลนส์แถบเมนูล่าง

Branch: `codex/topic-pills-neutral-lens-2026-11-12`

[ดาวน์โหลด ZIP](https://github.com/bossbazz98/korea-watch/archive/refs/heads/codex/topic-pills-neutral-lens-2026-11-12.zip)

- หมวดข่าวหน้าแรกอยู่ใต้ข่าวเด่นตามเดิม เรียงสองแถว ปัดแนวนอนพร้อมกัน ชื่อหมวดอยู่ซ้ายและจำนวนข่าวอยู่ในช่องเล็กด้านขวา ขนาดกล่องพอดีข้อความ
- หมวดข่าวหน้าบันทึกใช้กล่องเดียวกัน แต่เรียงหนึ่งแถว พร้อมจำนวนข่าวที่บันทึกในแต่ละหมวด กดกรองได้ตามเดิม
- ข้อความใต้หัวข้อข่าวเด่น คำว่า “ลบ” และกล่องหมวดข่าวหน้าบันทึกใช้ IBM Plex Sans Thai
- เลนส์แถบเมนูใช้พื้นและขอบสีโทนเดียว ขยายไอคอนจริงตามตำแหน่งเลนส์ ไม่มีสำเนาไอคอน ฟิลเตอร์สี ฟิลเตอร์เบลอ หรือ mask ซ้อนภายในเลนส์ คงการสไลด์แบบสปริง กดค้างขยาย ลากเลือก และขอบเฉพาะตอนกดค้าง

## นำขึ้นแอป

รุ่นนี้เปลี่ยนหน้าจอเท่านั้น ใช้การตั้งค่า Firebase เดิม และ deploy เฉพาะ Hosting:

```bash
cd ~/Downloads/korea-watch-codex-topic-pills-neutral-lens-2026-11-12
npm --prefix worker ci
npm --prefix worker run deploy:hosting
```

หลัง deploy ให้ปิดแอปแล้วเปิดใหม่เพื่อติดตั้งหน้าแอปรุ่นใหม่ สามารถตรวจรุ่นใน Console ได้ด้วย `document.documentElement.dataset.release` ซึ่งต้องได้ `20261112-topic-pills-neutral-lens`

## การตรวจสอบ

ทดสอบมือถือกว้าง 320/390 พิกเซล เดสก์ท็อป และโหมด standalone ที่ device scale 3 ทั้งธีมสว่างและมืด รวมกล่องสองแถว/หนึ่งแถว ปัดดูหมวด การกรอง จำนวนข่าว ฟอนต์ การลบบันทึก และการเปลี่ยนภาษาทั้งสามภาษา

การตรวจเลนส์ครอบคลุมช่วงแตะ กดค้าง ลาก ปล่อย และคืนตัว ตรวจทั้งเส้นสีม่วงแนวนอนและแนวตั้ง พร้อมตรวจทุกเฟรมว่าไม่มีฟิลเตอร์สี/เบลอหรือ mask ซ้อนอยู่ในเลนส์หรือไอคอนจริง แบบทดสอบเดิมตรวจภาพเฉพาะช่วงกดค้างและเส้นแนวนอน จึงไม่ครอบคลุมเส้นแนวตั้งช่วงเปลี่ยนขนาดตามวิดีโอ

ทดสอบด้วย Chromium จริงและจำลองขนาดมือถือ/standalone ไม่ใช่การทดสอบบน iPhone จริง WebKit ในคลาวด์ไม่มี executable และการดาวน์โหลดเคยถูกนโยบายเครือข่ายบล็อก หลัง deploy ควรตรวจท่าจากวิดีโออีกครั้งบน iPhone โดยแตะเมนูบันทึก กดค้าง ลากข้ามเมนูแล้วปล่อย ทั้งสองธีม
