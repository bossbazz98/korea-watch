# อัปเดตภาษาทั้งระบบและปุ่มหน้าอ่านข่าว

Branch: `codex/system-language-reader-actions-2026-11-12`

[ดาวน์โหลด ZIP จาก GitHub](https://github.com/bossbazz98/korea-watch/archive/refs/heads/codex/system-language-reader-actions-2026-11-12.zip)

รุ่นนี้ใช้ภาษาไทย อังกฤษ หรือเกาหลีที่เลือกในตั้งค่ากับเมนู หัวข้อข่าว สรุป เนื้อหา ข่าวที่บันทึก การแชร์ และแจ้งเตือนใหม่ ชื่อแบรนด์และชื่อสำนักข่าวยังเป็นชื่อของเจ้าของเดิม ปุ่มย้อนกลับ บันทึก และแชร์ในหน้าอ่านแยกกรอบ โดยย้อนกลับกว้างที่สุด

ข้อความแจ้งเตือนเรียงเป็น `KOREA WATCH` → ระดับความสำคัญ → หัวข้อข่าว โดยไม่มีสรุปข่าว แตะแล้วเปิดหน้าอ่านของข่าวนั้น ทั้งจากแอปที่เปิดอยู่และจากลิงก์ที่เปิดแอปใหม่ แจ้งเตือนรวมเปิดข่าวล่าสุดที่อ้างถึง หากข่าวออกจากฟีดและไม่มีสำเนาที่บันทึกไว้ จะแจ้งว่าไม่พบข่าว แทนการแสดงข่าวอื่น

## อัปเดตบน Mac

แตก ZIP ใหม่ แล้วรันจากโฟลเดอร์ใหม่ตามนี้ ใช้ Firebase และการล็อกอินเดิม ไม่ต้อง `firebase init`:

```bash
cd ~/Downloads/korea-watch-codex-system-language-reader-actions-2026-11-12
npm --prefix worker ci
./worker/node_modules/.bin/firebase deploy --project korea-watch01 --only firestore:rules
npm --prefix worker run deploy:hosting
```

ต้อง deploy rules ก่อน Hosting เพื่อให้บันทึก `lang: ko` ได้ จากนั้นปิดแอปแล้วเปิดใหม่ หรือรีโหลดหน้าเว็บ รุ่นหน้าเว็บตรวจได้จาก Console:

```javascript
document.documentElement.dataset.release
```

ต้องได้ `20261112-system-language`

## ให้ข่าวมีสรุปและเนื้อหาครบภาษา

Hosting เปลี่ยนหน้าจอ แต่ไม่รัน AI แปลข่าว ต้องใช้ worker รุ่นใหม่นี้ด้วย:

1. เปิด [Actions → Fetch news](https://github.com/bossbazz98/korea-watch/actions/workflows/fetch-news.yml)
2. กด **Run workflow** และเลือก branch `codex/system-language-reader-actions-2026-11-12`
3. กด **Run workflow** แล้วรอรอบนั้นเสร็จ
4. เปิดแอปใหม่หรือดึงลงเพื่อรีเฟรช

ข่าวใหม่ขอหัวข้อ สรุป และเนื้อหาทั้งสามภาษา ข่าวเก่าที่ขาดภาษาอังกฤษหรือเกาหลีจะทยอยเติมหลังงานข่าวใหม่ สูงสุด 4 ข่าวต่อรอบ ภายใต้เวลาและโควตา AI ที่เหลือ ไม่ส่ง push ซ้ำเพราะเติมภาษา หากภาษาที่เลือกยังไม่พร้อม แอปจะแสดงข้อความรอแปลในภาษานั้น

การรันด้วยมือบน branch ใหม่ไม่เปลี่ยน worker อัตโนมัติบน `main` หากทดสอบเรียบร้อยแล้ว เจ้าของโปรเจกต์ต้องตรวจและ merge branch นี้เอง จึงให้รอบอัตโนมัติใช้โค้ดใหม่ต่อเนื่อง ผู้ช่วยไม่ได้ merge หรือ deploy ให้

ตรวจสถานะการเติมภาษาได้จาก Terminal ในโฟลเดอร์เดียวกัน:

```bash
npm --prefix worker run diagnose:translation
```

ดู `workerBranch`, `workerCommit`, `missingLanguages` และ `localizedThisRun` จำนวนข่าวที่แสดงยังอยู่ภายใต้เพดานอายุ จำนวน และขนาดข้อมูลเดิม

## การตรวจสอบ

- ทดสอบ worker การแปลสามภาษา การเติมภาษาที่ขาดโดยไม่แจ้งซ้ำ และแจ้งเตือนตามภาษาของแต่ละเครื่อง รวมถึงเปลี่ยนภาษาระหว่างรอส่งซ้ำ
- ทดสอบรหัสข่าวและลิงก์แจ้งเตือนจาก FCM ทั้งแอปที่เปิดอยู่ แอปที่ยังเริ่มไม่เสร็จ ลิงก์เปิดแอปใหม่ การกลับจากเบื้องหลัง และการรีโหลดระหว่างเปิดข่าว
- ทดสอบ Chromium ที่ความกว้าง 320, 390, 1280 พิกเซล และโหมดแอป standalone รวมการอ่าน บันทึก แชร์และปุ่มแยก
- ทดสอบ Firestore rules ในคลาวด์ไม่ได้ เพราะเครือข่ายบล็อกการดาวน์โหลด emulator จาก `storage.googleapis.com` ไม่ได้ทดสอบกับฐานข้อมูล production หรือ iPhone จริง สามารถทดสอบ rules บน Mac ที่มี Java 21 และเครือข่ายพร้อมได้ด้วย `npm --prefix worker run test:rules`
