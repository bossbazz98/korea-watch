# อัปเดตแหล่งข่าว หมวดข่าว Kanit และการแชร์ภาพ

Branch: `codex/verified-news-kanit-sharing-2026-11-12`

รุ่นนี้รวมการแก้เมนูกองตอนเปิดแอปจาก branch ก่อนหน้า ยังไม่ได้ merge หรือ deploy ให้โดยอัตโนมัติ

## สิ่งที่เปลี่ยน

- ใช้เฉพาะ 24 สำนักที่ผู้ใช้เลือก ตรวจโดเมนจริงทั้งรับข่าวและเผยแพร่ ค้นแยกแต่ละสำนักเพิ่มผ่าน Google News ซึ่งเป็นตัวกลาง ไม่ใช่แหล่งข่าว
- หมวดทั่วไปต้องผ่านทั้ง AI และหลักฐานจากหัวข่าว/ช่วงต้นต้นฉบับ ไม่เพิ่มหมวดเพราะเจอคำผ่าน ๆ ข่าวที่ยืนยันหมวดไม่ได้เก็บในคิวส่วนตัวเพื่อตรวจใหม่ตามรอบ retry
- แรงงานต่างชาติต้องเกี่ยวกับชาวต่างชาติในเกาหลีใต้ ค่าแรงและประธานาธิบดีต้องเกี่ยวกับเกาหลีใต้ คนไทยในเกาหลีต้องมีความเชื่อมโยงไทย–เกาหลีใต้ ข่าว E-9 ทั่วไปไม่เข้าหมวดไทยอัตโนมัติ
- สงครามเกาหลีแยกจากการรบประเทศอื่น สงครามทั่วโลกไม่รับสงครามราคา/การค้าและการเตรียมพร้อมอย่างเดียว โรคติดต่อไม่รับไวรัสคอมพิวเตอร์
- ข่าวดังต้องมีอย่างน้อย 3 สำนักอิสระรายงานเรื่องเดียวกัน ภาษาอังกฤษ/เกาหลีของสำนักเดียวกันไม่นับซ้ำ JoongAng กับ Korea JoongAng Daily นับเป็นกลุ่มเดียว
- เหตุฉุกเฉิน 5 แบบที่ยืนยันแล้วและข่าวดังที่มีหลักฐานหลายสำนักเป็นข้อยกเว้นที่กฎยืนยันได้เอง หมวดทั่วไปต้องได้รับเลือกจาก AI ด้วย
- ข่าวเก่าจากสำนักที่ไม่อนุญาตถูกนำออกจากฟีดทำงาน ข่าวเก่าที่ต้องตรวจหมวดใหม่เข้าคิวส่วนตัว ไม่ส่งแจ้งเตือนซ้ำเมื่อแปลใหม่
- ใช้ Kanit ที่ฝังในเว็บและแคชออฟไลน์ สรุปกับเนื้อหาในหน้าอ่านข่าวยังใช้ Sarabun
- นำ “พื้นที่ของคุณ” ออกจากตั้งค่า ไม่มีการเชื่อม Cell Broadcast
- กล่องแชร์แสดง 2 แท็กและ `+จำนวนที่เหลือ` การแชร์ภาพส่งเฉพาะไฟล์ PNG ไม่มีข้อความ หัวข้อ หรือลิงก์แนบไปกับไฟล์ รูปแบบแชร์ลิงก์ยังใช้งานได้
- ระดับแจ้งเตือนคงเดิม: ด่วนมากเฉพาะ 5 เหตุที่ยืนยันแล้ว ระดับอื่นตามตัวเลือกและหมวดที่เลือก รองรับหัวข่าวภาษาอังกฤษตาม 5 เหตุเดิมด้วย

## แหล่งข่าว 24 สำนัก

Yonhap News Agency, Newsis, News1, KBS, MBC, SBS, JTBC, YTN, Arirang TV, Chosun Ilbo, JoongAng Ilbo, Dong-A Ilbo, Hankyoreh, Kyunghyang Shinmun, Hankook Ilbo, Maeil Business, Korea Economic Daily, Seoul Economic Daily, The Korea Herald, The Korea Times, Korea JoongAng Daily, Newstapa, NK News และ Daily NK

รายการโดเมนอยู่ที่ `public/news-policy.js` ใช้ร่วมกันทั้ง worker และหน้าเว็บ ไม่ใช้ Yonhap News TV ซึ่งไม่อยู่ในรายชื่อ ข่าวแต่ละรอบขึ้นกับข่าวที่เผยแพร่และ Google จัดทำดัชนี จึงไม่ใช่ว่าทุกสำนักจะมีข่าวที่ตรงหมวดในทุกรอบ

## อัปเดตหน้าจอบน Mac

ดาวน์โหลดและแตก ZIP:
https://github.com/bossbazz98/korea-watch/archive/refs/heads/codex/verified-news-kanit-sharing-2026-11-12.zip

เปิด Terminal แล้วรันจากโฟลเดอร์ใหม่:

```bash
cd ~/Downloads/korea-watch-codex-verified-news-kanit-sharing-2026-11-12
npm --prefix worker ci
npm --prefix worker run deploy:hosting
```

ใช้ Firebase ที่ล็อกอินไว้แล้ว ไม่ต้อง `firebase init` และไม่ต้อง deploy rules เพราะไม่ได้เปลี่ยน rules ปิดแอปให้หมดแล้วเปิดใหม่ หากแอปแสดงให้โหลดรุ่นใหม่ ให้ใช้ปุ่มโหลดรุ่นใหม่ที่มีอยู่

## ใช้กฎคัดข่าวใหม่

Hosting เปลี่ยนหน้าจอ แต่การค้นหาและแปลต้องรัน worker รุ่นใหม่ด้วย:

1. เปิด https://github.com/bossbazz98/korea-watch/actions
2. เลือก workflow **Fetch news** → **Run workflow**
3. เลือก branch `codex/verified-news-kanit-sharing-2026-11-12` แล้วรัน โดยใช้ Firebase ที่ตั้งไว้ใน GitHub Secrets
4. รันเสร็จแล้ว เปิดแอปและดึงลงรีเฟรช ตรวจสถานะจากโฟลเดอร์ใหม่ได้ด้วย:

```bash
npm --prefix worker run diagnose:translation
```

ตรวจ `workerBranch`, `workerCommit`, `lastRun`, `byCategory` และ `pendingByCategory` เพิ่ม `categoryReviewCount` สำหรับข่าวที่ยังยืนยันหมวดไม่ได้ กับ `excludedPublishers` สำหรับข่าวนอกแหล่งที่อนุญาตที่ถูกนำออกในรอบนั้น จำนวนข่าวอาจลดลงเมื่อคัดเข้มขึ้น

**รอบอัตโนมัติใช้ main:** Run workflow จาก branch ทดสอบมีผลเฉพาะรอบนั้น หากต้องการใช้กฎนี้ต่อเนื่อง เจ้าของต้องตรวจและ merge PR เข้า main เอง จากนั้นรัน Fetch news บน main หรือรอรอบอัตโนมัติ ไม่ควรรัน main รุ่นเก่าสลับกับ branch ทดสอบแล้วคาดว่าจะใช้กฎใหม่ถาวร

## การตรวจสอบและข้อจำกัด

ทดสอบ worker/นโยบายและ UI ด้วย Chromium รวมจอ 320/390 px จอใหญ่ โหมด standalone ที่ความละเอียด 3 เท่า สองธีม สามภาษา การแชร์เฉพาะไฟล์ภาพ และการไม่ส่งแจ้งเตือนข่าวเก่าซ้ำ ฟิกซ์เจอร์ใช้โดเมนในรายการอนุญาต แต่จำลอง RSS, AI และ Firebase ไม่ได้เปลี่ยนข้อมูล Firebase จริง

ยังไม่ได้ยืนยันฟีดสดครบ 24 สำนักหรือทดสอบบน iPhone จริง ให้ดูผล Fetch news และ `feedErrors` หลังรันจริง การจัดหมวดใช้ AI ร่วมกับกฎจำกัดขอบเขต จึงยังอาจมีข่าวที่ต้องตรวจเพิ่มเติม
