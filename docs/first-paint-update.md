# แก้ปุ่มเมนูกองมุมล่างซ้ายตอนเปิดแอป

Branch: `codex/first-paint-navigation-2026-11-12`

[ดาวน์โหลด ZIP รุ่นนี้](https://github.com/bossbazz98/korea-watch/archive/refs/heads/codex/first-paint-navigation-2026-11-12.zip)

สาเหตุที่ทำซ้ำได้: HTML เดิมวางปุ่มเมนูทั้งสามแยกกันอยู่ในแถบที่ใช้ `display:block` ต้องรอ JavaScript สร้างแถวเมนู จึงเห็นปุ่มเรียงลงมาจากมุมล่างซ้ายชั่วครู่ ก่อนกลับเข้าที่เมื่อสคริปต์โหลดเสร็จ

รุ่นนี้ใส่แถวเมนู ตัวครอบไอคอน และพื้นเลนส์ไว้ใน HTML ตั้งแต่แรก พร้อมตำแหน่งเริ่มต้นใน CSS สคริปต์ใช้โครงเดิมต่อเพื่อเพิ่มการลากและแอนิเมชัน ไม่ต้องย้ายปุ่มไปสร้างโครงใหม่ และยังรองรับ HTML รุ่นเก่าที่เก็บในแคช

## อัปเดตแอป

แตก ZIP ลง Downloads แล้วรัน:

```bash
cd ~/Downloads/korea-watch-codex-first-paint-navigation-2026-11-12
npm --prefix worker ci
npm --prefix worker run deploy:hosting
```

อัปเดตเฉพาะ Hosting โดยใช้ Firebase เดิม หลัง deploy ให้ปิดแอปแล้วเปิดใหม่ รุ่นหน้าเว็บตรวจได้จาก `document.documentElement.dataset.release` ซึ่งต้องได้ `20261112-first-paint-navigation`

## การตรวจสอบ

ทดสอบหน่วงไฟล์แอปและโมดูลเลนส์ 500 มิลลิวินาที ลดความเร็ว CPU เป็น 4 เท่า หน่วงฟอนต์ โหมด standalone ที่ความละเอียด 3 เท่า หน้าจอ 320/390/1280 พิกเซล ธีมสว่าง/มืด การแสดงผลเมื่อยังไม่มี JavaScript และการเริ่มทำงานกับ HTML รุ่นก่อน

ก่อนแก้ แบบทดสอบจับตำแหน่งปุ่มได้ที่ x เดียวกัน โดย y เรียงเป็น 780, 832 และ 884 พิกเซล สองปุ่มจึงล้นต่ำกว่าแถบเมนู หลังแก้ตรวจว่าปุ่มอยู่แถวเดียวกันภายในแถบตั้งแต่ภาพแรก และตำแหน่งปุ่มกับเลนส์ต่างจากหลังเริ่มสคริปต์ไม่เกิน 0.5 CSS px

ภาพช่วงฟอนต์ยังโหลดไม่เสร็จใช้การจับเฟรมจาก Chromium โดยตรง เพื่อไม่ให้คำสั่งถ่ายภาพรอจนฟอนต์โหลดเสร็จแล้วซ่อนอาการเริ่มต้น พร้อมตรวจเมนูหน้าแรก บันทึก ตั้งค่า และชุดทดสอบท่าทางเดิม การทดสอบในคลาวด์ใช้ Chromium และการจำลองมือถือ ไม่ใช่ iPhone จริง
